# Singly Linked Lists

## Description
This project introduces singly linked lists in C. It covers how to create, traverse, manipulate, and free linked lists using dynamic memory allocation.

## Learning Objectives
By completing this project, I learned how to:

- Understand the structure of a singly linked list.
- Create and traverse linked lists.
- Add and remove nodes.
- Manage dynamically allocated memory.
- Avoid memory leaks.

## Requirements

- Ubuntu 20.04 LTS
- GCC with the following flags:
  ```bash
  -Wall -Werror -Wextra -pedantic -std=gnu89
  ```
- Betty coding style.

## Files

| File | Description |
|------|-------------|
| `lists.h` | Header file containing the `list_t` structure and function prototypes. |
| `0-print_list.c` | Prints all elements of a `list_t` linked list. |

## Compilation

Example:

```bash
gcc -Wall -Werror -Wextra -pedantic -std=gnu89 \
0-main.c 0-print_list.c -o a
```
