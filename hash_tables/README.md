# Hash Tables

This project is about hash tables and hash functions in C.

## Learning Objectives

- Understand what a hash function is.
- Understand what makes a good hash function.
- Understand how hash tables work.
- Understand collisions and collision handling.
- Understand the advantages and drawbacks of hash tables.

## Tasks

- Create a hash table.
- Implement a hash function.
- Implement hash table insertion.
- Implement hash table lookup.
- Implement hash table deletion.
- Free a hash table.

## Requirements

- Ubuntu 20.04 LTS
- GCC
- Betty coding style
- Compilation flags:
  `-Wall -Werror -Wextra -pedantic -std=gnu89`
