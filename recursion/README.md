# Recursion

This project introduces recursion in C.

## Learning Objectives

* What recursion is
* How to implement recursion
* When to use recursion
* When not to use recursion

## Requirements

* Compiled with `gcc`
* Uses `-Wall -Werror -Wextra -pedantic -std=gnu89`
* No loops
* No global variables
* No standard library functions
* Uses `_putchar`
